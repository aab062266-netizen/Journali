# Journali

Journali is a simple journal app for iPhone. You can write your thoughts and find them again easily.

## Features
- Splash screen when the app opens
- Write a journal with a title and text
- Edit a journal by tapping it
- Delete a journal by swiping it, with a confirmation message
- Bookmark your favorite journals
- Sort journals by bookmark or by date
- Search journals
- Warning before leaving a journal you did not save
- Your journals stay saved after you close the app

## Extra features
- **Show Bookmarked Only:** in the filter menu, show only the journals you bookmarked.
- **List / Grid view:** a button next to the filter button switches between cards in a list and cards side by side. In grid view, press and hold a card to delete it.

## Technologies
Swift, SwiftUI, MVVM (Model, View, ViewModel), UserDefaults, SF Symbols, Xcode, GitHub.
